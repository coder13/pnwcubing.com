# PNWCubing.com

Public website for Pacific Northwest Cubing, built with Next.js and deployed on Vercel.

## Documentation

- Architecture and operations: [docs/architecture-and-operations.md](/home/cailyn/projects/pnwcubing.com/docs/architecture-and-operations.md)

## Development

```bash
yarn dev
```

Useful checks:

```bash
yarn lint
yarn build
```
